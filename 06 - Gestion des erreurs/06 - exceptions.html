1. Lancer : throw

On crée un objet exception et on le lance. La fonction s’arrête immédiatement. 
if (b == 0)
    throw std::runtime_error("division par zéro");

2. Surveiller : try

Seules les exceptions lancées pendant le bloc try (y compris dans les fonctions appelées) peuvent être attrapées par ses catch.

3. Attraper : catch

Les catch sont testés dans l’ordre. Le premier dont le type correspond (ou est une classe parente) gagne ; les autres sont ignorés.

4. Du plus précis au plus général

catch (const std::exception&) attrape tout ce qui en dérive : placé en premier, il « masquerait » les catch suivants. 
catch (const std::out_of_range& e) { … } // précis
catch (const std::exception& e)    { … } // général

5. Par référence constante

Toujours catch (const Type& e) : pas de copie, et le polymorphisme fonctionne (e.what() donne le bon message).

6. Et si personne n’attrape ?

L’exception remonte toute la pile jusqu’à sortir de main : le programme est arrêté brutalement par std::terminate().
